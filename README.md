# Mythic releases

Installers for **Mythic**, a media studio that runs on your own computer and graphics card. It makes images, video, audio, 3D and ads with no cloud.

- **Download:** the newest `Mythic_x.y.z_x64-setup.exe` from [Releases](../../releases/latest).
- **Needs:** Windows 10 or 11, 64-bit, and an NVIDIA graphics card.
- **Updates:** an installed Mythic checks this page and offers new versions in Settings → About. Each download is checked against the sha256 in that release's `latest.json`.

The source code is not in this repository; it holds only installers and release notes.
